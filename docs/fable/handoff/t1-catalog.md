# t1-catalog handoff

- Variant `production` (catalog/js/asset-loader.mjs): built by `AssetRuntime` (assetSet modular, quality high, published overrides ignored) from `FAMILIES` in src/kit/index.js, reached only through four new exports in `labs/shared/game.js` (`loadKitIndexModule`, `loadKitRuntimeModule`, `loadKitContractModule`, `loadKitMaterialsModule`; all tagged 20261113a — bump with the others). The allowlist is the registered kit ids. A family merged later needs no catalog change: it appears in the inspector, the swap board and the compare view by itself.
- Inspector: a "Production" button (disabled "classic only" when the id has no kit asset) and a link to `preview.html?variant=compare` (original / lab study / production side by side) and the swap board. preview.html adds a tier switch and controls generated from `params` (catalog/js/param-controls.mjs); `?tier=` and `?params={json}` are honoured.
- Swap board: `catalog/swap.html` (+ `js/swap.mjs`, `swap.css`). Variant classic/modular and params per kit asset; saved through `GET/POST /api/asset-library/kit-overrides` (catalog/server.mjs) to the repo-root `kit-overrides.json`, atomic (temp + rename), serialized, revision = sha256 prefix of the file bytes (`none` when absent), ids allowlisted by `scanKitIds` (text scan of `defineAsset({ id:` under src/kit, never evaluated). On a static host the board downloads the file. Entries equal to the defaults are dropped; the file keeps exactly the game's format (no extra keys).
- Thumbnails: `thumbnails.json` gets a `production` map (28 WebP, 360x300, 252 KB). To regenerate after new families: open `catalog/preview.html?asset=<id>&variant=production&tier=hero` headlessly and `toDataURL('image/webp', .82)` (script pattern in the report).
- Pending patches for other lanes: none. `tools/catalog_check.mjs` was extended (production thumbnails); not a hot file, but outside `catalog/**` — Integrator please accept.
- Test change: `catalog/tests/model.test.mjs` jade-paw coverage `related` -> `direct`, because v-keepsakes (cb8ff3f) added a direct keepsakes/jade-paw lab target; it failed on the integration base before this lane.
- Known limit: server-side param validation is shape-only (the schemas need three.js); the swap board clamps to the schema and the game's `resolveParams` clamps again.
- t1-catalog merge: catalog/js/links.mjs now resolves the new ranges benches (foothill-stands, village, mists) and interiors craft benches (frame, tokonoma, scroll, chabudai, zabuton, bonsai, knockables) added by v-ranges/v-interiors-a.
