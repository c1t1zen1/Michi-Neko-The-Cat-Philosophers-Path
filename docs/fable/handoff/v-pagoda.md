# v-pagoda handoff

## Inventory row (labs/asset_inventory.json) for `distant-pagoda`
Set `production`: `{ "family": "pagoda", "adapter": "distant-pagoda", "status": "kit" }` (use the same shape the merged rocks/garden rows use), part names:
`podium`, `storey_1..storey_5` (hero/mid), `tower` (far), `sorin`. Params: preset, height_scale, storeys, roof, paint, age.

## Other consumers
- s3-vista (summit Higashiyama pagoda): `import { buildTower } from '../kit/pagoda/index.js?v=<tag>'` and build with `preset: 'yasaka'`, or call `buildPagoda({preset, H, ...}, { detail: 'hero'|'mid'|'far', material })` with a vertex-colour material (`ctx.kitMaterials.bag({rough: 0.78, brush: 0.05})`). `buildTower` divides H by `layout.scale`, so a layout scale does not change the world height.
- r4-festival (Roof Road): same, any preset (`muroji`, `daigoji`...).
