## Design decisions (documented in `runtime.js` and guide §3)

1. **Tiers vs `_mergeStatics()`**: tier chosen once at build time from quality × distance band (`TIER_POLICY`: high → near hero / rim mid / far far; medium one step less; low never reaches the kit); instances merge like classic geometry unless in `live`; `setTier` only for instances that implement it, called from `setQuality()`; merged statics re-tier on the next boot; no runtime handover ⇒ AAA-4 holds by construction. `medium.near = mid` until budgets (D1) say otherwise.
2. **Materials merge** via `KitMaterials.bind(MAT)` (called by `setContext({ MAT })`): zero change to the merge code; f2's only lines are `assets.setContext({ MAT, textures: TEX })` and protecting `instance.live` roots.
3. **Footprint registration** = ruling R12, in §3.4 with a `placeAsset` sketch; runtime defaults `footprint` to `layout.footprint`; contract test compares them.
4. **Local-space rule**: builders build at the origin, +y up; the owner places the group from the layout.
5. **`kit-overrides.json`** is fetched only when the set is not classic or a `?swap` asks for the kit ⇒ the classic default makes no extra request.
6. **Capture determinism**: the uuid-stream split was necessary — the optional summit GLB finishes parsing on a variable frame and its object creation shifted the shared seeded stream (first a/b runs differed in ~330 px). With the split, two boots are pixel-identical.
