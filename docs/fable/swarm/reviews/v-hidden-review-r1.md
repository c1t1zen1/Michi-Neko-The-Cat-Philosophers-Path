### Named risks
1. Build order / rects: PASS. The kit changes nothing in `hidden_places.js`; `placeAsset` (hidden_places.js:121-150) registers `out.footprint || layout.footprint` once, in the same call order. Every kit asset takes `layout.footprint` by default; children carry `footprint: {}`. The reported modular systems golden (135 colliders / 5 water / 4 exclusions / 5 anchors) is consistent with that. Kit builders consume only `ctx.rng` (per-asset `assetRng`, runtime.js:314), so the layout stream is untouched.
2. Mist: classic quiets the pool in mist AND rain (`calm = weather==='rain'||'mist' ? 0.5 : 1`, hidden_places.js:833; used for caustic opacity and motes). Kit `calmAt` reads `env.wet` only, and `main.js:586` sets `env.wet = weatherAmount('rain')`. So this is a real, small regression: in mist the caustics stay at 0.4 and motes at full strength. It is not an AAA-5 legibility hit (just calm/mood), but a two-line hot-file patch fixes it (see Important 1).
3. Rest anchors: PASS. `poolRestPos` / `gladeRestPos` come from the layout footprint (hidden_places.js:233, 582), which the kit never touches. The seat slabs are visual only (pool top ~9.3 cm vs classic 9 cm; harmless).
4. Reuse: partly. Greenery culm/blade builders are imported, not copied (glade.js:9). The rocks helpers and lanterns `washiTexture`/`haloTexture`/`kindle`/`nightnessAt` are imported. The toro is NOT reused "as is": see Important 2.
5. Live draws: pool = water, caustic, moon sprite, glints (hero), motes points, toro lamp/halo. Glade whole = lit paper (1 mesh, 11 lanterns), halos (1 draw), fireflies = ~3-4 live draws vs classic ~44 lantern draws + sprites. Reported 118→92 and 125→108 calls, +0.7%/+1.0% tris. Credible. Caveat: the 3-draw win exists only in whole mode; the per-part `glade-lanterns` child builds its own 3 meshes per lantern (11 x 3 = 33 draws), which is worse than classic's own merged path if swapped alone.

### Strengths
- One lit-paper mesh for N lanterns via an `aK` vertex attribute and one billboard halo mesh is a smart draw-call fix and avoids the point-size clamp (common.js `billboardSet`, glade.js `paperSetMaterial`).

- `compose()` fuses parts so whole and child assets share one code path; textures cached per layout via `shared()` and never freed by instances.

### Issues
#### Critical

#### Important
1. **Mist regression, patch not handed off.** `src/kit/hidden/common.js` `calmAt` uses `env.wet` only; classic also halves on mist (hidden_places.js:833). The handoff §4 calls it a "small deviation" and §8 says "none needed". Fix by handoff patch: `src/main.js:586` add `env.mist = this.sky.weatherAmount('mist');` (and `mist: 0` in the initial env at 584 and runtime.js:172), then `calmAt = 1 - 0.5*sstep(0.15,0.5, max(env.wet||0, env.mist||0))`. Put the exact patch in handoff §8 so the Integrator can apply it. Until then the kit is not behaviour-equal to classic.
2. **Pool toro option table is copy-pasted, not reused.** pool.js (`buildMoonPool`) calls `buildStoneLantern(ctx, {index:0}, {girth:1, flame:0.5}, { kind:'kasuga', height:1.14, kasaR:0.3, halo:{scale:1.5,fog:false}, base:0.2, gain:2.0 })`, duplicating `src/kit/lanterns/index.js:33`. If v-lanterns tunes pool-toro the pool silently drifts. The brief said REUSE; import the `pool-toro` asset def from `../lanterns/index.js` and call its `build`, or have lanterns export the option object. It also drops `L.toro.angle` (placement has no `ry`) — check that classic's toro was not rotated by it.
3. **Lotus standing leaf looks wrong.** moon-pool-22-cat-modular.jpg: the hero "standing leaf" is a flat dark saucer on a thin pole rising above the bloom, reading like a bird-bath or table rather than a lotus leaf (pool.js `lotusGeometry`, dish `polarDisc(0.19, ... y:0.07*rn²)` at lh 0.30-0.42 m, a stem with no leaf curve). Brief AAA-1 claim "lotus on stems with a standing leaf" is overstated. Make it a cupped, tilted leaf, lower than or beside the bloom, or drop it from hero.

#### Minor
1. glade.js `buildLanternSet`: classic lanterns bob (`lamp.position.y += sin(t*1.1+phase)*0.03`, hidden_places.js ~line 862); the kit drops the sway. Mention in the status or restore with the aH/aK vertex attribute trick.
2. pool.js `rimVariants` is a module-level Map keyed by seed/detail/facets that is never cleared; fine in size but is shared mutable state outside `ctx`/`dispose`. Confirm `placed()` clones, or key it through `shared(km, ...)`.
3. Per-part `glade-lanterns` child builds a whole set (frame, paper, halo) per lantern; if classic parent places 11 child instances they cost 33 draws. Note in handoff that swap is intended as a whole, or merge across instances.
4. Pool rim is darker than classic's pale stones at night/pre-dawn (rocks default colours, self-reported). Legible, but a stone-lightening `tint` param default for this family would keep the "moon on pale stones" read.
5. Stills cannot judge motes/fireflies/glints; recommend the Integrator eyeball one live capture at hour 22.
6. Handoff §1 states the exceptions are not committed on this branch; they are in the worktree's budgets.js, so make sure the integrator commit includes that file, otherwise 14 contract rows fail.
