04

Back to the valley

What would move into the game, and what it would cost.

  • One instanced mesh. Three hundred and forty twigs is a single draw, and the placement is a few lines. It replaces the torus with something that holds up to the cat being right next to it.
  • Keep the collectible. The golden feather is a quest reward at the top of the climb. It needs the same trigger and position.
  • Save it, don’t build it. Run the placement once at load. The bird is for the lab; the game only needs the finished nest.
  • Michi’s nest should be Michi-sized. The game’s nest is small for a cat to sit in. The lab’s is scaled up, and the game’s should match if Michi is going to curl up in it.
