04

Back to the valley

What would move into the game, and what it would cost.

  • Eye-shine is two sprites. An additive sprite on each eye marker, driven by an angle test against the player’s lantern. It’s very cheap, since it only appears when in line.
  • Temperament is already a table. The PERSONALITIES table in npc.js covers idle weights and greetings. Nothing here changes that.
  • Sprites need depth off. Otherwise the eye sprite is hidden by the head mesh it sits on. Glow goes on top, which suits it.
  • Coat changes are real rebuilds. Each build is sculpted once per body type and cached, so a cat’s look is cheap after the first time.
